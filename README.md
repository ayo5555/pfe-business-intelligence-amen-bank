# Business Intelligence & Data Analytics Project

## Overview

This project was developed as part of my final-year internship
and focuses on the design and implementation of a Business
Intelligence solution for data analysis and decision support.

## Technologies

- Power BI
- SQL Server
- SSIS
- Python
- Machine Learning
- DAX

## Project Architecture

The project follows a complete BI workflow:

1. Data extraction
2. Data transformation using SSIS
3. Data integration into SQL Server
4. Data modeling
5. KPI development
6. Power BI dashboard creation
7. Exploratory Data Analysis
8. Machine Learning
9. Model evaluation

## Business Intelligence

The solution includes interactive Power BI dashboards
for monitoring KPIs and analyzing business performance.

## Machine Learning

Machine Learning models were developed to perform
predictive analysis using:

- Logistic Regression
- Random Forest

The models were evaluated using appropriate performance metrics.
